## ADDED Requirements

### Requirement: 页图临时写入 SHALL 兼容 Windows 深路径

页图渲染器 SHALL 使用不包含最终制品长文件名的短 PNG 临时文件完成写入，并在成功后原子替换最终文件。

#### Scenario: 深路径中的缩略图写入

- **当** 最终缩略图路径位于深层 Windows 临时目录中
- **则** 临时 PNG 名称不包含最终制品的哈希文件名或 `.thumbnail` 标记
- **且** 写入成功后最终页图和缩略图路径、制品 ID 与既有缓存行为保持不变

#### Scenario: 临时写入失败

- **当** PNG 写入或原子替换失败
- **则** 不得留下临时文件
- **且** 不得修改已有最终制品
