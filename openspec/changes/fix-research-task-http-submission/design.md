# 设计：修复 HTTP 入口的研究任务提交

## 根因

`ResearchTasksPage` 在提交前直接调用 `crypto.randomUUID()`。该 API 仅在安全上下文可用；公共 HTTP IP 地址不是安全上下文，因此异常发生在 Axios 请求之前。

## 最小方案

- 以时间戳与 `Math.random()` 生成仅供客户端提交使用的任务 ID，不依赖安全上下文 API。
- 在页面捕获 Axios 错误时读取服务端 `detail.message` 或 `detail`；其他异常展示其可读消息，避免把所有问题归因到预算。
- 保持 API 请求体、DAG 步骤、权限判断和成功后的刷新逻辑不变。

## 验证

- 在测试中移除全局 `crypto` 后提交任务，断言请求仍被调用且任务 ID 符合前缀约定。
- 模拟服务端 422，断言页面展示服务端原因。
- 运行研究任务页定向测试、静态检测与前端构建。
