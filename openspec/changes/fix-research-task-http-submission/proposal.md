# 变更提案：修复 HTTP 入口的研究任务提交

## 背景

正式研究台通过公共 HTTP 地址访问时，浏览器不提供 `crypto.randomUUID()`。研究任务页在发起请求前调用该 API 生成任务 ID，导致请求未到达后端，并被统一错误文案误报为会话、范围或预算问题。

## 目标

- 在 HTTP 与 HTTPS 入口均可生成可用的客户端任务 ID。
- 提交失败时优先展示服务端返回的可读原因，网络错误保留明确提示。
- 不改变任务 API、审批流程、权限、预算模型或已有数据。

## 非目标

- 不调整服务端任务 ID、认证机制、预算单位或执行流程。
- 不改动其他页面、部署入口和容器配置。
