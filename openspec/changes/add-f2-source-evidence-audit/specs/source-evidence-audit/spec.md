## ADDED Requirements

### Requirement: 发布前来源证据必须可定位

评测 CLI 在接收到显式来源根目录时 MUST 检查每个答案样本声明的来源文件是否可定位，并在缺失时输出具体缺失列表与非零结果；未提供来源根目录的无密钥夹具模式保持不变。

#### Scenario: 来源文件缺失

- **WHEN** 样本声明的来源文件不在任何显式来源根目录下
- **THEN** 报告列出缺失文件并返回非零结果
- **AND** 不得将评测结果标记为来源证据就绪

#### Scenario: 来源文件存在

- **WHEN** 样本声明的来源文件能在任一显式来源根目录下定位
- **THEN** 报告将来源审计标记为就绪
- **AND** 不改变其他确定性评估指标
