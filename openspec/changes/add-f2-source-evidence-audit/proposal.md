# F2 来源证据审计

## Why

当前评测样本只校验来源文件名和页码格式，不检查在受控评测环境中是否存在对应来源文件。这样可能把“来源声明完整”误读为“来源证据可审计”，尤其是在历史 PDF 未随候选工作树提供时。

## What Changes

- 增加只读来源证据审计器，按评测样本的 `expected_sources` 检查显式来源根目录。
- 评测 CLI 增加可重复的 `--source-root` 参数；发现缺失来源文件时生成审计结果并返回非零。
- 未传入来源根目录时保持现有离线夹具模式，不要求 CI 携带真实 PDF。

## Non-Goals

- 不下载、复制或修改 PDF。
- 不把历史来源清单、未跟踪 SQLite 或缺失的 PDF 自动转成已复核样本。
- 不改变评测数值、单位、期间、拒答和工具轨迹评估逻辑。
