## ADDED Requirements

### Requirement: 来源文件必须绑定冻结清单

评测 CLI 在同时接收到显式来源根目录和来源清单时 MUST 对每个样本声明的来源文件核对清单登记、文件存在性、SHA-256、文件大小和物理页数；任一项不一致时 MUST 输出具体失败项并返回非零结果。

#### Scenario: 来源文件与清单完全匹配

- **WHEN** 样本来源文件能在显式来源根目录定位，且其 SHA-256、文件大小和物理页数与清单一致
- **THEN** 来源完整性审计标记为就绪
- **AND** 评测 CLI 保留其他确定性指标并返回原质量门禁结果

#### Scenario: 来源文件发生漂移

- **WHEN** 来源文件存在但 SHA-256、文件大小或物理页数任一项与清单不一致
- **THEN** 报告列出对应漂移类型和文件
- **AND** CLI 返回非零结果

#### Scenario: 来源未登记或清单未提供

- **WHEN** 样本来源文件未登记在清单中
- **THEN** 完整性审计标记为未就绪并列出未登记文件
- **AND** 未提供 `--source-inventory` 时保持既有仅存在性审计行为
