# F2 来源完整性绑定审计

## Why

现有来源审计只确认样本声明的文件名是否能在显式来源根目录中找到，无法证明该文件就是冻结来源清单中的同一份 PDF，也无法发现文件被替换、大小漂移或物理页数变化。隔离候选需要把外部来源根目录与版本化清单绑定，才能为后续 F2 和主分支合并提供可复核的来源证据。

## What Changes

- 增加只读来源完整性绑定审计器，按样本来源文件匹配冻结清单，并核对 SHA-256、文件大小和物理页数。
- 评测 CLI 增加可选 `--source-inventory` 参数；只有同时提供来源清单时才启用完整性绑定，结果写入报告并在不一致时返回非零。
- 保持既有 `--source-root` 的存在性审计和无来源根目录的离线夹具行为兼容。

## Non-Goals

- 不下载、复制、修改或删除 PDF。
- 不修改完整候选集、复核包、签核台账或 `release_ready` 状态。
- 不把来源完整性通过等同于人工复核、真实 Provider、v5.19 baseline 或成本对比通过。
