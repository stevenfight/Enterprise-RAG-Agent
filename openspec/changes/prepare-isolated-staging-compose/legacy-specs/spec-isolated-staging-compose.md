# 需求：隔离服务器测试 Compose 配置

## R1：测试栈不得占用正式资源

测试 Compose 必须使用与正式栈不同的容器名、网络、本机端口和数据目录，且不得挂载 `./data` 或宿主机 `./config`。

## R2：测试栈默认不公网暴露

后端和前端端口必须绑定 `127.0.0.1`，并保持通过前端 Nginx `/api` 的同源代理。

## R3：测试凭据不得进入版本库

测试 Compose 必须引用未跟踪 `.env.staging`；已跟踪模板只能包含占位值和安全说明。

## R4：共机资源必须受限

测试服务必须设置 `restart: "no"` 及保守的 CPU、内存限制，避免服务器重启或资源竞争影响正式服务。
