# 规格：财务研究工作台 UI 改造

## 要求：研究工作台上下文

首页必须在不改变既有问答 API 的前提下，把研究范围、结论和证据组织在同一工作区。

### 场景：发起研究问题

- **当** 用户进入首页并选择公司或 Agent 模式
- **则** 页面清晰显示当前公司范围、当前模式和系统在线状态
- **且** 用户可以继续使用现有输入框发起问题

### 场景：跨路由研究上下文

- **当** 用户在研究工作台选择公司范围或模式后切换到其他路由
- **则** 当前应用运行期间的研究上下文保持一致
- **且** 刷新页面后该新增上下文按现有前端状态策略重置，不作为浏览器或后端持久化记录
- **且** 页面不得将该前端状态表述为已保存的研究项目或跨设备记录

### 场景：理解提问范围

- **当** 用户在全局顶栏或研究工作台看到公司范围与模式摘要
- **则** 页面明确说明该摘要仅影响下次提问
- **且** `topN` 与 Agent 步数上限仍是首页高级选项，不作为全局研究上下文
- **且** 历史消息不因当前摘要而被标记或推断为使用了该公司范围或模式

### 场景：窄屏全局研究上下文

- **当** 视口宽度小于 1200px 且用户处于任一路由
- **则** 顶栏将只读研究上下文收纳为可访问的上下文按钮或底部抽屉
- **且** 该入口只显示下次提问范围和模式，不提供第二个编辑入口
- **且** 它不与主题、健康状态、证据、分析过程或移动端固定输入区遮挡

### 场景：阅读研究结论

- **当** 问答返回答案、KPI 或来源
- **则** 主画布优先展示结论和 KPI，证据面板展示来源文件、页码和现有检索分数
- **且** 缺失页码或分数时不显示伪造值
- **且** 检索分数标注为“检索匹配度”，不得表述为答案可信度
- **且** KPI 原样展示解析出的数值和单位，不换算、不合并、不补全未知口径
- **且** 收入、利润等普通数值不因正数而使用上涨或成功语义色

### 场景：理解证据范围

- **当** 用户查看某个回答的来源面板
- **则** 页面将来源说明为该回答的检索证据
- **且** 在当前 API 未返回指标—来源映射时，不声称来源可逐项证明某个 KPI

## 要求：可核验分析过程

产品不得向用户呈现模型内部思维文本，应只呈现可核验的分析过程。

### 场景：查看 Agent 过程

- **当** Agent 返回步骤信息
- **则** 页面展示工具调用、输入摘要、观测摘要、步骤状态和风险提示
- **且** 不渲染 `thought` 字段的内部文本
- **且** 输入和观测摘要经过允许字段筛选、长度限制与敏感字段脱敏
- **且** 不展示原始请求头、令牌、密钥、授权信息、运行配置、绝对路径或堆栈

### 场景：安全保存过程状态

- **当** 单 Agent 或多 Agent 的步骤被写入消息 Store 或浏览器持久化
- **则** `agentEvent` 在 Store 写入前先转换为不含 `thought` 的 `AnalysisTraceStep` 安全过程视图模型
- **且** 单 Agent 的 `thought`、多 Agent 的 `thought` 步骤内容、原始输入和原始观测均不得进入持久化数据
- **且** 工具名、Worker 名称和输入键必须映射为受控产品标签，未知值不得原样显示或持久化
- **且** 加载已有浏览器会话时清理遗留过程字段与原始工具/Worker 名称并立即回写，不删除用户问题或最终回答
- **且** 原有过程、消息和顶栏测试迁移为安全模型与三态状态断言，不删除测试用例规避回归

## 要求：专业研究设计系统

视觉系统必须以阅读、数据比较和状态核验为优先，不得以马卡龙渐变或玻璃效果作为主信息层级。

### 场景：默认主题

- **当** 用户未选择深色主题
- **则** 页面使用浅色研究画布、中性卡片和单一品牌强调色
- **且** 数字与 KPI 使用等宽字体，语义状态不只依赖颜色

### 场景：系统健康状态

- **当** `AppLayout` 的健康检查尚未完成、成功或失败
- **则** 顶栏分别显示“检查中”“已就绪”或“暂不可用”
- **且** 不在健康检查完成前将未知状态误报为离线

### 场景：深色专注模式

- **当** 用户切换深色主题
- **则** 图表、DAG 和证据区保持可读对比度
- **且** 深色模式仍使用相同的语义状态颜色

## 要求：页面能力边界

图表、资料库、DAG 与设置页必须提升层级，但不得承诺现有 API 未提供的数据。

### 场景：资料库元数据

- **当** 资料库 API 只返回文件名、大小、上传时间和索引状态
- **则** 页面只展示这些已知字段
- **且** 不从文件名推断公司、年度、章节或引用次数

### 场景：分析成果为空

- **当** 图表列表为空
- **则** 页面说明如何从研究工作台生成图表
- **且** 不显示虚构的研究成果卡片

## 要求：响应式、性能和可访问性

所有改造页面在桌面与移动端都必须保持关键研究信息和可操作性。

### 场景：窄屏查看证据和流程

- **当** 视口宽度小于 1024px
- **则** 证据和流程面板可收起为抽屉或底部面板
- **且** 不挤压答案主画布或固定输入区

### 场景：减少动态效果

- **当** 用户启用系统减少动态效果偏好
- **则** 页面禁用非必要的循环或入场动画
- **且** 不影响任务状态和加载反馈
