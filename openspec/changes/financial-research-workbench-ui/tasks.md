- [x] A2. 已新建全红 TDD，覆盖主题 token、研究上下文、证据过程、响应式和可访问性。

## 工作包 B：研究工作台

- [ ] B1. 在不改变现有请求与流式逻辑的前提下，将 `ChatPage` 拆分为研究摘要条、主研究画布、证据面板和固定输入区。
- [ ] B2. 复用现有公司选择、Agent 开关、消息、KPI、来源和输入组件，建立 `ResearchContextBar`、`ResearchWelcome`、`EvidencePanel` 等界面组件；来源分数统一标注为检索匹配度。
- [ ] B3. 将 `ThoughtChainDrawer` 与 `MessageBubble` 的过程预览共同重构为“分析过程”，只展示工具、输入摘要、观测、状态和风险提示，不渲染 `thought`。
- [ ] B4. 保留流式回答、超时、错误、会话与滚动行为，并为工作台新增空、加载、错误和强制停止状态。

## 工作包 C：辅助页面一致性

- [ ] C1. 升级图表页为分析成果页，使用现有 `ChartData` 增加类型/数量摘要、统一卡片和空状态引导。
- [ ] C2. 升级资料库页的概览、上传和索引状态层级；只使用现有资料库 API 字段。
- [ ] C3. 升级 DAG 页的高级分析流程定位、状态语义和窄屏降级。
- [ ] C4. 升级系统状态页的分组、状态层级和错误/加载状态，保持只读能力。
