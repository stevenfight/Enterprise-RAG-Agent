# 变更提案：财务研究工作台 UI 改造

## 背景

当前前端已具备智能问答、Agent 执行过程、图表、DAG、知识库和系统状态等能力，但这些能力分散在五个偏工具化页面中。整体视觉仍采用马卡龙粉紫和玻璃拟态，和企业财务研究所需要的可信度、数据密度及长文阅读体验不完全匹配。

本变更将前端从“功能集合”调整为“财务研究工作台”：以一个研究任务为中心组织问题、结论、关键指标和可核验证据，同时保留现有路由、API 和 Agent 能力。

## 目标

1. 建立适合财务研究的设计系统：浅色研究画布为默认，深色专注分析模式为可选主题。
2. 将聊天首页改造成研究工作台，串联公司范围、提问、结论、KPI、引用和可核验分析过程。
3. 升级图表、知识库、DAG、设置页面的信息层级和状态表达，统一为同一套研究语言。
4. 保持现有 API 契约和业务能力，首期不依赖新增后端字段。

## 非目标

- 不改变 RAG、Agent、检索、鉴权、SSE 或数据入库业务逻辑。
- 不展示或新增模型内部思维链；仅展示用户可核验的工具、检索和证据过程。
- 不通过文件名推断并显示公司、报告年度、章节或可信度等未知元数据。
- 不将回答级来源伪装为某个 KPI 的逐项引用，也不擅自换算、汇总或赋予财务数值涨跌语义。
- 不展示原始工具输入、请求头、令牌、密钥、运行配置或堆栈等可能包含敏感信息的过程字段。
- 不将上述原始过程字段写入浏览器会话持久化；对既有浏览器会话中的过程字段只做安全投影或清理，不影响用户问题与最终回答。
- 首期不新增“保存研究报告”“团队协作”“文档全文预览”等需要后端持久化的数据功能。
- 不重构为 Ant Design Pro、Tailwind 或其他前端框架。

## 交付边界

本变更分为四个工作包：

1. 设计系统与全局工作台框架。
2. 智能问答页的研究工作台重构。
3. 图表、知识库、DAG、设置页的一致性升级。
4. 响应式、可访问性、性能与视觉验收。

## 成功标准

- 用户在首页可在一个上下文中看见研究范围、提问、结论、KPI、引用与任务状态。
- 默认界面具备企业研究产品的清晰层级，不再以马卡龙渐变和大面积玻璃效果作为主视觉。
- 所有既有路由和核心交互可用；前端现有测试、构建与新增 TDD 验收通过。
