## ADDED Requirements

### Requirement: 研究操作必须按权限、审计和预算边界执行

系统 MUST 对工具风险、提示词注入、关键状态变更和成本预算采用显式控制，并让审计回放不泄露敏感输入或来源正文。

#### Scenario: 检索内容含有指令

- **WHEN** 外部检索内容包含试图改变 Agent 行为的指令
- **THEN** 系统将其作为不可信数据隔离，不将其提升为系统或工具指令

#### Scenario: 预算超过允许范围

- **WHEN** 研究步骤的预计或累计成本超过批准预算
- **THEN** 系统拒绝继续执行并保留可审计的预算原因
