## ADDED Requirements

### Requirement: 多模态财报处理必须复用可证明制品并显式处理低置信内容

系统 MUST 只复用能定位且可证明兼容的既有解析制品；视觉提取的财务数值必须关联页面和置信信息，不能静默替代文本证据。

#### Scenario: 既有完整制品可证明兼容

- **WHEN** 文档版本、页码和处理版本与既有 MinerU 制品一致
- **THEN** 系统复用该制品而不重复调用解析器

#### Scenario: 扫描页数值置信度不足

- **WHEN** 视觉提取的财务数字低于允许置信阈值
- **THEN** 系统将其标为待复核，不将其作为已核验金融事实发布
