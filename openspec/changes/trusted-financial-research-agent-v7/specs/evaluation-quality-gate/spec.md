## ADDED Requirements

### Requirement: 金融 Agent 评测必须使用可治理的版本化数据集和分层门禁

系统 MUST 校验版本化黄金样本的来源与页码，并以可复现的答案、声明、单位和轨迹指标输出候选与基线差异；无密钥回放不得冒充在线模型质量。

#### Scenario: 发布评测集不满足治理要求

- **WHEN** 发布模式的数据集未复核或覆盖不完整
- **THEN** 质量门禁拒绝通过并返回非零结果

#### Scenario: 关键数量级错误出现

- **WHEN** 候选答案存在超过容差的关键数量级错误
- **THEN** 即使平均指标较高，分层门禁仍判定失败
