# 规格 E：研究工作流与可审计报告

## 要求：研究计划协作

### 场景：创建研究任务

- **当** 用户提交研究目标和范围
- **则** 系统生成可查看的计划、数据范围、预计成本和风险点

### 场景：调整计划

- **当** 用户在执行前修改范围
- **则** 重新计算受影响步骤和预算
- **且** 不修改无关步骤

## 要求：冲突审核

### 场景：存在待确认冲突

- **当** 报告依赖尚未裁决的关键金融事实
- **则** 报告进入待审核状态
- **且** 用户可以查看双方来源并批准、驳回或保持未决

## 要求：声明级报告

### 场景：生成报告

- **当** 研究任务达到报告生成条件
- **则** 每个关键声明关联事实、计算、来源或明确的分析判断标签
- **且** 报告记录生成版本、数据版本和时间

### 场景：来源变化

- **当** 某事实被修订或失效
- **则** 只使依赖该事实的声明进入待复核
- **且** 其他已验证声明保持有效

## 要求：渐进导出

### 场景：首版导出

- **当** 用户导出首版报告
- **则** 先保证 Markdown/HTML 内容和证据完整

### 场景：文档格式扩展

- **当** 后续增加 PDF、Word 或 Excel
- **则** 每种格式均有独立布局与证据完整性验收
- **且** 不因格式转换丢失声明 ID 和来源关系

## 要求：复用现有界面

### 场景：新增任务工作台

- **当** 实现研究任务页
- **则** 复用现有布局、主题、DAG、证据面板和图表组件
- **且** 不重写已稳定聊天功能
