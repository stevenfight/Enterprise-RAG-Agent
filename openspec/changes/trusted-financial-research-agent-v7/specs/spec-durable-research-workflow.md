# 规格 C：可恢复研究任务

## 要求：C0 通用执行基础先于多模态

PDF 解析、视觉调用和索引构建必须使用 C0 的 ExecutionRun、StepAttempt、Checkpoint、Invocation、TaskEvent 和 Lease；M 不得建立平行状态机。

### 场景：多模态入库中断

- **当** 入库任务在视觉调用或索引 staging 阶段中断
- **则** 从 C0 最近有效检查点恢复
- **且** 已成功且依赖版本一致的调用不得重复

### 场景：功能依赖未开启

- **当** multimodal_enabled 为 true 但 financial_trust_enabled 或 durable_execution_enabled 未显式开启
- **则** 严格配置校验失败并阻止多模态写路径启动
- **且** 不自动修改其他功能开关

## 要求：并发命令与租约

状态变更必须使用 command_id、expected_revision 和 CAS；执行者只有持有有效 lease 才能提交结果。

### 场景：并发暂停与取消

- **当** 两个客户端基于同一 revision 分别暂停和取消任务
- **则** 只有一个 CAS 成功，另一个返回冲突和当前 revision
- **且** 重复提交相同 command_id 返回原结果

### 场景：执行者失联

- **当** lease 过期且原执行者不再续租
- **则** 新执行者可领取新 attempt
- **且** 原 attempt 的晚到结果不得提交

## 要求：任务状态机

### 场景：合法迁移

- **当** 运行中任务被暂停、等待审批、完成或失败
- **则** 状态按批准的迁移表更新
- **且** 记录操作者、原因和时间

### 场景：非法迁移

- **当** 尝试恢复已取消任务或完成未满足依赖的步骤
- **则** 拒绝操作并保持原状态

## 要求：原子检查点

### 场景：步骤完成

- **当** DAG 步骤成功完成
- **则** 步骤结果、状态、事件序号和工具调用记录在同一事务边界持久化

### 场景：保存失败

- **当** 检查点写入失败
- **则** 不把步骤对外报告为已完成
- **且** 允许安全重试

## 要求：幂等恢复

### 场景：进程中断

- **当** 服务在部分步骤完成后重启
- **则** 从最近有效检查点恢复
- **且** 已完成步骤及成功工具/模型调用默认不重复
- **且** 已成功的有副作用工具绝不自动重复执行

### 场景：输入发生变化

- **当** 恢复时工具规范化输入与原幂等记录不同
- **则** 不复用旧结果
- **且** 创建新的调用记录或要求重新审批

依赖比较必须包含代码/工具版本、模型与 provider、提示词、事实/制品版本和 index generation，不能只比较工具参数。

## 要求：失败处理

### 场景：可重试错误

- **当** Worker 发生批准列表中的暂时性错误
- **则** 在有限次数和退避规则内重试

### 场景：不可重试错误

- **当** 输入校验、权限或业务规则失败
- **则** 不自动重试
- **且** 保存失败分类和人工可读原因

### 场景：超时调用晚到

- **当** 线程或远端模型在等待超时后仍返回结果
- **则** 将结果记录为 discarded
- **且** 不得写入事实、制品、索引或完成状态，也不得启动后续步骤

## 要求：流式重连

### 场景：客户端断线

- **当** 客户端携带最后事件 ID 重新连接
- **则** 服务补发缺失事件后继续实时流
- **且** 不重复展示已确认事件

### 场景：游标超过保留窗口

- **当** 客户端最后事件 ID 早于服务端最旧保留事件
- **则** 明确要求先获取当前任务快照再重连
- **且** 不把不连续事件伪装成完整补发

### 场景：事件流鉴权

- **当** 客户端订阅持久任务事件
- **则** 使用可携带 Authorization 的流式请求并校验任务访问权限
- **且** 不复用旧 EventSource 免鉴权路径，不在 URL 传长期 API Key

## 要求：兼容与显式失败

### 场景：使用既有即时问答

- **当** 用户继续调用 `/api/agent/query` 或 `/api/agent/stream`
- **则** 保持既有接口和响应兼容

### 场景：持久任务执行路径失败

- **当** ResearchTask 已选择 single 或 multi 路径后发生失败
- **则** 保存失败状态并等待显式重试或重新规划
- **且** 不静默切换执行路径
