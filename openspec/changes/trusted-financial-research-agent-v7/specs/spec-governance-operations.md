# 规格 D：安全、审计与成本治理

## 要求：工具权限

### 场景：低风险工具

- **当** 任务调用只读检索或纯计算工具
- **则** 可按策略自动执行并记录审计事件

### 场景：高风险工具

- **当** 工具被分类为外部写入或特权操作
- **则** 必须获得与规范化参数绑定的有效审批
- **且** 审批过期或参数变化时重新审批
- **且** task revision、计划、事实/制品版本或 index generation 变化时旧审批失效

### 场景：当前没有外部写工具

- **当** 当前版本只有只读检索和纯计算工具
- **则** 不为演示审批而新增虚构写工具
- **且** 审批应用于关键冲突裁决和正式报告签发

## 要求：提示词注入隔离

### 场景：检索内容包含指令

- **当** 文档内容试图覆盖系统规则或诱导工具调用
- **则** 将其视为不可信数据而非指令
- **且** 记录安全事件

### 场景：跨 Agent 污染

- **当** 上游 Worker 输出包含未授权操作指令
- **则** 下游只消费结构化数据和允许字段

## 要求：审计与脱敏

### 场景：任务回放

- **当** 审核人员查询任务
- **则** 可按时间还原计划、工具、审批、关键输入输出、模型版本和最终结论

### 场景：关键状态与审计原子性

- **当** 系统消费审批或提交关键状态迁移
- **则** 业务状态、审批消费和审计事件在同一 V7MetadataStore 事务提交
- **且** 不允许出现已执行但无审计或已审计但实际未执行

### 场景：敏感字段

- **当** 输入或输出包含配置的敏感字段
- **则** 在日志、追踪和报告持久化之前脱敏

## 要求：成本预算

### 场景：接近预算

- **当** Token、调用次数、费用估算或时间接近预算
- **则** 系统产生预警并避免启动非必要分支

### 场景：超过预算

- **当** 任务达到硬预算
- **则** 安全暂停并保存检查点
- **且** 不将不完整结果标记为完成

## 要求：路由可解释

### 场景：选择 single 或 multi

- **当** 路由器选择执行路径
- **则** 保存复杂度、风险和成本依据
- **且** 可在评测报告中比较质量、延迟和成本
