## ADDED Requirements

### Requirement: 金融事实必须带上下文归一并可审计地处理冲突

系统 MUST 持久化版本化金融事实及其单位、币种、期间、口径和来源上下文；只有可安全比较的事实才能归一、计算或判定冲突。

#### Scenario: 口径或期间不兼容

- **WHEN** 两个待比较事实的期间类型、合并范围、会计准则或审计状态不一致
- **THEN** 系统拒绝把它们当作数值冲突或直接计算输入

#### Scenario: 同口径事实超出容差

- **WHEN** 同一指标、同一期间和同一口径的事实归一后超出容差
- **THEN** 系统创建可审计的 `VALUE_CONFLICT` 并进入待裁决状态
