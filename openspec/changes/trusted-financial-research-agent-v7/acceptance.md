# v7.0 验收口径与阶段决策

## 指标定义

| 指标 | 定义 | 首版目标 | 启用阶段 |
|---|---|---:|---|
| 数值正确率 | 正确关键数值断言数 ÷ 已评测关键数值断言数；同时要求单位、币种、期间和口径兼容 | ≥ 98% | A 基线，B 硬门禁 |
| 答案级来源命中率 | 命中预期来源/页码的样本数 ÷ 要求来源的样本数 | 先记录基线 | A |
| 声明级证据支持率 | 被证据直接支持的关键事实声明数 ÷ 需要证据的关键事实声明数 | ≥ 95% | B |
| 无依据关键声明率 | 缺少支持证据的关键事实声明数 ÷ 全部关键事实声明数 | ≤ 3% | B |
| 正确拒答率 | 正确拒答或明确证据不足的样本数 ÷ 应拒答样本数 | ≥ 95% | A/B |
| 工具轨迹符合率 | 满足必须调用、禁止调用和顺序约束的样本数 ÷ 有轨迹约束样本数 | 基线后批准 | A |
| 表格关键单元格准确率 | 数值、正负号与数量级均正确的关键单元格数 ÷ 已标注关键单元格数 | ≥ 97% | M |
| 表格结构 F1 | 对表头层级、行列关系和合并单元格的 precision/recall 调和平均 | ≥ 90% | M |
| 视觉单位/期间准确率 | 单位与期间均正确的视觉事实数 ÷ 已标注视觉事实数 | ≥ 95% | M |
| 图表趋势准确率 | 趋势方向与标注一致的系列数 ÷ 已评测系列数 | ≥ 90% | M |
| 区域定位命中率 | bbox 与标注区域 IoU≥0.5 的证据数 ÷ 有区域标注的证据数 | ≥ 95% | M |
| 低置信拦截率 | 未被错误提升为 verified 的低置信视觉案例数 ÷ 低置信案例数 | ≥ 95% | M |
| 高风险视觉误入库数 | 核心财务数字错误但被标为 verified 的高风险视觉案例数 | 0 | M |
| 无证据视觉声明率 | 无对应 artifact、页码及可用区域/明确 unresolved 标记的视觉事实声明数 ÷ 视觉事实声明数 | ≤ 3% | M |
| 源 PDF 完整性 | 迁移前后 SHA-256 不一致的源 PDF 数 | 0 | M |
| 处理决策覆盖率 | 有完整复用/重处理决策与证据的当前文档版本数 ÷ 当前文档版本数 | 100% | M |
| 首轮索引覆盖率 | 已进入并通过首个 v7 generation 完整性校验的 active 文档版本数 ÷ 迁移基线 active 文档版本数 | 100% | M |
| 溯源引用完整率 | 外键有效且可回溯到 document version/artifact 的事实、声明、计算与报告关系数 ÷ 全部已发布关系数 | 100% | M/E |
| 恢复成功率 | 通过的受控故障场景数 ÷ 计划执行的受控故障场景数 | 100% | C |
| 重复执行数 | 恢复后被错误重复执行的已完成步骤或成功调用数 | 0 | C |
| 未审批关键操作数 | 未经有效审批完成的关键冲突裁决、正式报告签发或真实高风险调用数 | 0 | D/E |

“恢复成功率 100%”仅表示规格中预先定义并实际运行的受控故障集全部通过，不代表生产环境永不失败。

## 性能与成本口径

- 延迟分别记录首事件时间、总耗时和 P95，不只记录平均值。
- 成本优先记录输入/输出 Token、模型调用次数和工具调用次数。
- 金额估算必须携带模型价格版本和生效日期；价格未知时只报告 Token，不猜测金额。
- 比较 single/multi 时必须使用同一数据集、模型配置、索引版本和运行次数。
- 多模态另行记录：总页面数、路由到视觉模型的页面/区域比例、缓存命中率、每类视觉任务调用次数、输入图像像素、Token、失败率和单文档 P95；M 基线完成前不编造固定金额阈值。
- M 阶段批准成本门禁时必须同时给出当前基线、目标值、模型价格版本和“质量下降换成本下降”的拒绝边界；视觉模型调用比例只能用于成本观察，不能为了压低调用率跳过必要难例。

## 数据集覆盖配额

核心文本/Agent 完整集不少于 100 条，但不能依靠简单事实问题凑数。建议最低覆盖：

| 类别 | 最少样本 |
|---|---:|
| 单一事实与页码 | 15 |
| 数值、单位、币种、期间 | 20 |
| 确定性财务计算 | 15 |
| 多公司/多文档比较 | 15 |
| 冲突检测与无法裁决 | 15 |
| 证据不足与拒答 | 10 |
| 工具路由、异常和安全 | 10 |

同时满足：至少 4 家公司、至少 2 个报告期、至少 3 类来源；同一模板只替换公司名的样本不得全部计为独立覆盖。

另建不少于 40 个页级或区域级案例的多模态专集。它可以与 100 条完整集引用同一源文档，但必须使用独立 case ID、区域标注和指标分母，不得把同一页面的多个字段任意拆分来虚增覆盖：

| 多模态类别 | 最少案例 |
|---|---:|
| 普通财务表格 | 10 |
| 跨页续表 | 5 |
| 多级/复杂表头 | 5 |
| 柱线饼等财务图表 | 8 |
| 扫描页或无文本层页面 | 5 |
| 脚注、单位与口径区域 | 4 |
| 正文—表格/图表冲突 | 3 |

每个视觉案例至少记录 PDF 哈希、页码、区域标注、制品类型、标准结构/事实、允许误差、复核状态和标注工具版本。区域定位指标只计算具备可靠 bbox 标注的案例；未标注案例不得被当作命中。

多模态数据分为开发集和冻结留出集。留出集至少占 25%，按文档或公司分组拆分，禁止同一表格、同一图表或其裁剪变体同时进入开发集和留出集。提示词、路由规则和阈值只能在开发集调整，最终门禁报告必须单列留出集结果。

40 个案例是 v7.0 工程验收下限，用于证明链路、边界和可复现性，不足以宣称对所有行业、报表版式或生产分布具有统计泛化能力。若留出集任一高风险数值被错误标为 verified，即使平均指标达标也 No-Go。

## 样本复核协议

1. 编制者记录标准答案、来源、页码、摘录和计算过程。
2. 复核者在不查看系统答案的情况下独立核对来源。
3. 单人项目允许由同一人分两轮完成，但必须间隔执行、记录两个时间戳和复核结论，不能伪称两名人员审核。
4. 有争议的样本标为 pending_review，不进入发布门禁。
5. 任何阈值调整都要保留前后值、理由和批准记录。
6. 视觉标注必须保留原页图哈希和标注版本；模型输出不得被直接回填为黄金答案。

## 阶段 Go/No-Go

### A → B

- Go：核心回放门禁稳定、完整集复核完成、v5.19 基线可复现。
- No-Go：样本 schema 不稳定、基线不可重现或高风险错误被平均分掩盖。

### B → C0

- Go：结构化事实、确定性计算和冲突核验达到批准指标，旧事实接口兼容。
- No-Go：仍依靠提示词进行核心计算，或无法裁决时仍输出确定结论。

### C0 → M

- Go：租约、revision/CAS、检查点、依赖版本幂等和晚到结果隔离全绿，模拟入库可恢复。
- No-Go：超时线程仍可提交结果，或 M 需要自建任务状态、重试器和事件表。

### M → C1

- Go：源 PDF 哈希零变化、处理决策和首轮 v7 索引覆盖率均为 100%、新代际可回滚、关系溯源无悬空引用；开发集与冻结留出集达到批准阈值，高风险视觉误入库为 0，成本报告完整，缺页/未解析/低置信状态可见，旧文本链路无回归。
- No-Go：修改源 PDF、无证据复用旧向量、发布失败改变旧 active publication、索引/文档/制品/事实不属于同一快照或存在悬空溯源；或视觉结果使用第二套单位/事实/来源逻辑，无法定位时猜测 bbox，视觉模型不可用时静默生成确定结论。

### C1 → D

- Go：状态机、检查点、恢复、幂等和事件补发全部通过受控故障集。
- No-Go：服务重启会重复已完成调用，或旧即时问答出现回归。

### D → E

- Go：审批、审计、脱敏和预算边界可验证。
- No-Go：审计无法重建任务，或安全样本只靠提示词声明通过。

### v7.0 发布

- A、B、C0、M、C1、D、E 必选门禁全部通过。
- Markdown/HTML 报告属于必选交付；PDF、Word、Excel 是后续独立子变更，不阻塞 v7.0 首发。
- 后端、前端、构建、完整评测、受控故障、安全集和远端 CI 均有可核查记录。
- README、CHANGELOG、OpenSpec 项目路线和交接文档已同步。

## 求职成果验收

- 一张目标架构图，能说明评测平面、可信内核、任务状态与治理边界。
- 一份 v5.19 与 v7.0 的量化对比报告，失败样本不隐藏。
- 五段可复现演示：复杂研究、数字冲突、表格/图表视觉证据、中断恢复、安全审批。
- 七个可回答的架构问题：确定性计算边界、证据支持判定、裁判偏差、视觉路由与成本、幂等恢复、成本路由、为什么不整体迁移框架。
- 多模态案例必须同时展示一个成功定位案例和一个因缺页、低置信或能力不可用而拒绝下结论的失败案例，不能只展示最佳样本。
- 页面预览与区域高亮支持键盘操作，并提供结构化表格/图表文本说明；不能把截图作为唯一信息载体。
