# v7.0 分阶段路线图

## 总体依赖

```text
A 评测与门禁
  ↓ 提供质量尺度
B 金融可信内核
  ↓ 提供可信事实与计算
C0 通用可恢复执行基础
  ↓ 提供入库任务状态、检查点与幂等
M 可验证多模态财报理解
  ↓ 提供表格、图表与扫描页事实
C1 可恢复研究任务产品化
  ↓ 提供稳定长流程
D 安全、审计与成本治理
  ↓ 提供企业控制
E 研究交付工作流
```

## A：金融评测基线与发布门禁

### 输入

- 现有 10 条生成数据、10 条检索数据及历史报告。
- `tests/eval_langsmith.py`、`tests/eval_openevals.py`、`src/monitoring.py`。
- `.github/workflows/quality-gate.yml` 基础门禁。

### 升级内容

- 设计版本化评测数据格式和校验器。
- 先建立 30 条核心高风险集，再扩展到不少于 100 条完整集。
- 建立确定性评估器：数值、单位、币种、期间、引用页码、关键词、拒答、工具轨迹。
- 建立可选语义评估器：正确性、相关性、证据支持度。
- 生成机器可读 JSON 和人类可读 Markdown 报告。
- 保存当前基线与候选版本差异。
- 在 CI 中回放固定输出与工具轨迹，验证无密钥核心评估器和门禁；在线 LLM 全量评测保持手动或受控工作流。
- 阈值不通过时使门禁失败。

### 退出门禁

- 数据集 schema 校验全绿。
- 30 条无密钥核心集可在 CI 稳定运行。
- 100 条完整集经人工复核并可本地运行。
- 基线报告记录当前真实结果，不修饰失败样本。
- 回归差异能定位到样本、指标、代码与数据版本。
- A 阶段证据指标明确标记为答案级近似基线；声明级 95% 硬门禁留到 B 阶段。

## B：金融可信内核

### 升级内容

- 新建不可变金融事实实体，保留原始值和归一值。
- 建立指标词典、单位换算、币种、期间和统计口径模型。
- 将现有人工事实注册表适配到统一事实服务，保留原行为。
- 扩展确定性计算器，要求输入事实 ID、公式、精度和结果来源链。
- 建立冲突检测与裁决：单位、期间、口径、来源、真实数值冲突。
- 生成声明级证据包并对接现有回答证据链。

### 退出门禁

- 现有三大运营商比较结果完全兼容。
- 单位、期间、口径和币种边界测试全绿。
- 关键财务计算均可回溯到事实 ID 和公式。
- 冲突无法裁决时明确返回“需人工确认”，不静默选择。
- A 阶段指标达到批准后的目标值。

## C0：通用可恢复执行基础

### 升级内容

- 在 V7MetadataStore 中定义 ExecutionRun、StepAttempt、Checkpoint、Invocation、TaskEvent 和 Lease，不绑定研究任务 UI。
- 使用 revision/CAS 保护状态命令，重复暂停/恢复/取消保持幂等，过期 revision 不覆盖新状态。
- 检查点、调用账本和事件序号在同一数据库事务提交；并行 Worker 事件由单一持久化写入器分配单调 event ID。
- 幂等键包含规范化输入、代码/工具版本、模型、提示词、事实/制品版本和索引 generation；依赖版本改变时禁止错误复用。
- 超时和取消采用协作式 cancellation token 与 attempt token；底层线程或远端调用无法真正取消时，晚到结果只能记录 discarded，不得提交成功状态。
- 建立运行租约与重启接管规则，防止同一步骤被两个执行者并发领取。

### 退出门禁

- 同一 Run 不会被重复领取，过期租约可安全接管。
- 并发暂停/恢复/取消只有一个 revision 成功，重复命令幂等。
- 超时或取消后的晚到结果不能复活步骤或写入事实/索引。
- M 阶段可直接使用 C0 执行一条模拟入库流程，不需自建状态机。

## M：可验证多模态财报理解

### 输入

- 当前全部源 PDF 的只读哈希基线、页数、加密/可读状态和逻辑文档映射。
- 现有 MinerU VLM 生成的 Markdown、`images/` 引用、HTML/Markdown 表格和公式结果。
- PyMuPDF 页数、文本层与页图能力，以及 `build_line_page_map()` 的既有近似文本页码。
- B 阶段的 `FinancialFact`、统一归一器、来源权威度和 EvidenceBundle。
- A 阶段独立版本化的多模态评测专集。

### 升级内容

- 建立 staging 上传、不可变内容版本和派生目录边界；源 PDF 不被覆盖、清洗或反写。
- 对每个当前文档记录 `REUSE/ENRICH/TARGETED_REEXTRACT/FULL_REEXTRACT` 决策与证据，优先复用合格 MinerU 产物，只重处理明确缺失或困难范围。
- 为基线全部 active 文档侧向构建首个 v7 完整索引 generation；旧 embedding 因缺少完整版本证据统一重算，旧 publication 在新发布集合提交前保持 active。
- 建立 `DocumentAssetManifest`，清点 PDF 页、MinerU 图片、表格、公式、解析批次、哈希、定位状态和完整性；已有制品优先复用。
- 使用 PyMuPDF 建立幂等页图与缩略图服务，以文档哈希、页码和渲染版本缓存，不引入第二套 PDF 渲染包。
- 对页面进行确定性路由：文本、表格、图表、扫描、混合；正常文本页继续走原 RAG，不把全部页面发送给视觉模型。
- 表格按“MinerU HTML/Markdown 结构优先，复杂表头或结构损坏才进入视觉模型”的顺序处理；保留 row/colspan、单位、期间、脚注和跨页续表关系。
- 图表解析结构化提取标题、图例、横纵轴、单位、期间、系列、数据点及趋势，并把结果与页面文字交叉核验。
- 仅在没有可用文本层或既有 MinerU 结果不足时处理扫描页；当前环境未安装独立 OCR 包，实施前须核查 MinerU/视觉模型能力，禁止静默安装或伪造识别结果。
- 把可信视觉结果写入同一 `FinancialFactService`，使用同一单位、期间、冲突和来源策略；低置信结果只作为候选证据，不进入已验证事实。
- 在现有 `SourceInfo`、EvidencePanel、SourceCard 和 EvidenceChainGraph 上增加可选页图、区域高亮、artifact ID 与完整性警告。
- 将图片、OCR 文本和图表标签视为不可信数据，执行视觉提示词注入、越权指令和异常文件安全评测。
- 删除或重建知识库时同步清理或失效页图、区域图、制品清单、视觉事实和索引，防止孤儿数据。
- 以 SQLite 外键关系连接文档版本、制品、事实、声明、计算和报告；当前阶段不引入知识图谱或图数据库。

### 退出门禁

- 当前文档处理决策覆盖率为 100%，迁移前后源 PDF 哈希变化数为 0。
- 首轮 v7 generation 覆盖基线全部 active 文档，构建/校验失败不改变旧 active publication，发布后可整组回滚 index/document/artifact/fact 可见性。
- 关系型溯源无悬空引用，事实或文档版本失效能列出受影响声明、计算与报告；未引入未经评测证明的知识图谱。
- 多模态专集不少于 40 个区域级案例，覆盖普通表格、复杂/跨页表格、图表、扫描页、脚注和文本—视觉冲突。
- 专集按文档/公司拆分开发集与至少 25% 的冻结留出集，禁止同源裁剪变体跨集合；40 例只作为工程验收下限，不作为生产泛化证明。
- 表格关键数值单元格准确率不低于 97%，结构 F1 不低于 90%，单位与期间准确率不低于 95%。
- 图表趋势判断准确率不低于 90%；任何图表事实均能定位到文档、页码和区域或明确标记定位未解析。
- 有区域标注的样本定位命中率不低于 95%，命中要求 IoU 不低于 0.5；无法定位时不得猜测 bbox。
- 低置信或证据不足案例正确拒绝进入已验证事实的比例不低于 95%。
- 冻结留出集中高风险视觉数字错误进入 verified 的数量为 0；平均分不得掩盖此项硬失败。
- MinerU 缺页、视觉模型不可用和制品缺失都能显式产生 incomplete 状态，不存在静默文本回退。
- 原纯文本检索、问答、上传、证据链和图表生成指标不低于批准基线。
- 报告视觉路由比例、缓存命中、调用量、失败率和 P95；成本门槛在 M 基线后留痕批准，不以降低必要识别覆盖换取成本。

## C1：可恢复研究任务产品化

### 升级内容

- 将 ResearchTask、TaskStep 和 Planner/DAG 语义映射到 C0 的 ExecutionRun/StepAttempt，不再新建第二套执行状态。
- 定义状态机：pending、running、waiting_approval、paused、completed、failed、cancelled。
- 每个 DAG 步骤完成后原子保存检查点。
- 为可恢复工具和模型调用补充研究任务依赖版本并复用 C0 幂等键。
- 支持暂停、恢复、取消、超时、有限重试和失败分类。
- 服务重启后恢复未完成任务，不重复已完成副作用。
- SSE 重连后按持久事件序号补发任务事件；新任务流使用可携带 Authorization 的 fetch streaming，不复制旧 EventSource 免鉴权路径。
- 新增持久任务 API，保留现有即时问答 API；选定执行路径失败时不静默切换。

### 退出门禁

- 三种注入故障均可恢复：Worker 异常、进程中断、客户端断连。
- 已完成步骤及成功工具/模型调用默认不重复；有副作用调用绝不自动重复。
- 状态迁移无非法跨越。
- 失败、暂停、等待审批在前端可区分。

## D：安全、审计与成本治理

### 升级内容

- 建立工具风险等级和权限策略。
- 关键冲突裁决、正式报告签发及未来真实高风险调用进入人工审批，批准范围与参数绑定；不新增仅用于演示的危险工具。
- 记录不可抵赖式任务审计事件，但不伪称具备监管合规认证。
- 扩展 Prompt Injection 测试到检索内容、工具参数和跨 Agent 上下文。
- 对日志和报告进行敏感字段脱敏。
- 建立任务 Token、模型调用、工具调用和预算统计。
- 先用规则进行复杂度路由，再评估是否需要多模型路由。

### 退出门禁

- 未批准高风险操作执行为 0。
- 审计日志可重建一次任务的关键决策与执行路径。
- 安全集攻击样本全部达到预期阻断或隔离结果。
- 超预算任务能够在安全边界停止并保留检查点。

## E：研究任务与报告交付

### 升级内容

- 新建研究任务工作台，不重写现有聊天页。
- 支持研究计划查看、调整和关键节点审批。
- 展示事实、计算、冲突、声明与来源之间的关系。
- 生成带版本、来源、页码、公式和风险提示的研究报告。
- 支持报告重生成时保持证据引用稳定。
- v7.0 首发只把 Markdown/HTML 作为必选；Word、PDF、Excel 导出分别作为后续独立 OpenSpec 子变更，不阻塞首发。

### 退出门禁

- 用户能完成“创建计划—执行—审核冲突—生成报告”的完整流程。
- 报告中的关键声明均能定位证据或明确标为分析判断。
- 数据修改后只使受影响的声明失效，不污染其他已验证结论。

## 延后增强

### G：MCP/A2A

独立 OpenSpec：只暴露稳定的检索、计算、冲突核验能力，必须包含认证、超时和审计。

### H：知识图谱与行业情报

独立 OpenSpec：至少 30 个经复核的多跳关系案例必须先证明关系型方案无法达到批准门禁，并明确实体消歧、时态关系或图推理需求。

## 求职展示交付

- 5 分钟主流程演示。
- 升级前后评测对比报告。
- 数字冲突核验演示。
- 同一财报的复杂表格、图表与文本交叉核验演示，并可打开页图定位原始区域。
- 服务中断与恢复演示。
- Prompt Injection 和审批阻断演示。
- 架构决策记录：为什么采用确定性计算、为什么分离会话记忆与任务检查点、如何控制评测裁判偏差。
