## 使用说明

前端 TDD 采用"手动验证 + 浏览器测试"模式（非传统单元测试）。每条测试用例需要在开发完成后，在浏览器中手动验证通过后才能标绿。

可通过以下方式辅助自动化测试：
- Vitest + React Testing Library（组件单元测试）
- Playwright（端到端 E2E 测试）
- Chrome DevTools Lighthouse（性能/可访问性）
