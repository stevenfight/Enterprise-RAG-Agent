## SPEC-FE-002: 对话首页

### 描述
核心问答页面，用户输入问题后调用 `/api/query` 接口，展示回答和引用来源。

### 场景

| ID | 场景 | 预期 |
|----|------|------|
| FE-002-01 | 进入对话首页（无历史消息） | 显示欢迎语："您好，我是企业财务年报分析助手。请输入您的问题。" 以及 3-4 个示例问题快捷入口 |
| FE-002-02 | 在输入框输入问题并点击发送（或 Enter） | 消息列表新增用户消息气泡（右对齐，蓝色背景），输入框清空并禁用，显示加载动画 |
| FE-002-03 | 后端正常返回答案 | 消息列表新增 AI 消息气泡（左对齐，白色背景），展示 answer 文本，移除加载状态，输入框恢复可用 |
| FE-002-04 | 后端返回包含 sources 的答案 | AI 消息下方展示"引用来源"卡片列表，每张卡片显示：文档名、页码（可选）、相关度分数 |
| FE-002-05 | 点击引用来源卡片 | 展开/收起原文片段 (snippet) |
| FE-002-06 | 后端返回 error | 显示错误消息气泡："抱歉，服务暂时不可用，请稍后重试。（错误详情: xxx）" |
| FE-002-07 | 后端响应超时 (120s) | 显示超时提示："请求超时，请检查网络连接或稍后重试。" |
| FE-002-08 | 发送空消息 | 输入框显示校验提示，不允许发送 |
| FE-002-09 | 连续发送多条消息 | 消息列表自动滚动到最新消息，用户消息和 AI 消息交替显示 |
| FE-002-10 | 消息中包含 Markdown 格式文本（如**粗体**、表格、列表） | AI 回答正确渲染 Markdown（使用 react-markdown 或 Ant Design Typography） |

## SPEC-FE-007: SSE 流式传输与 Agent 推理

### 描述
后端新增 `/api/agent/stream` SSE 端点，前端通过 EventSource 实时接收 Agent 推理步骤。

### 场景

| ID | 场景 | 预期 |
|----|------|------|
| FE-007-01 | 开启 Agent 深度推理后发送查询 | 前端连接 `/api/agent/stream`，Content-Type 为 `text/event-stream` |
| FE-007-02 | SSE 事件到达 | 每条事件包含 type(thought/action/observation/answer)、step(序号)、content(文本)、timestamp(时间戳) |
| FE-007-03 | 流式传输过程中 | 前端逐条渲染中间步骤，非等全部完成后才显示 |
| FE-007-04 | SSE 连接意外断开 | EventSource 自动重连，3 秒内恢复 |
| FE-007-05 | 同时发送两个 SSE 请求 | 各自接收独立的事件流，数据不串扰 |
| FE-007-06 | 查询无结果（如乱码查询） | 返回空事件流，前端不报错不崩溃 |

## SPEC-FE-008: Agent 思维链可视化

### 描述
思维链侧边抽屉 (ThoughtChainDrawer) 用于完整展示 Agent 推理的 Think → Act → Observe 循环。

### 场景

| ID | 场景 | 预期 |
|----|------|------|
| FE-008-01 | Agent 模式产生推理步骤 | 消息气泡内显示折叠推理过程摘要 + "展开详情"按钮 |
| FE-008-02 | 点击"展开详情" | 右侧滑出抽屉，时间线样式展示完整推理步骤列表 |
| FE-008-03 | Thought 步骤 | 显示思考图标 + 浅紫色背景，文本内容为 Agent 思考过程 |
| FE-008-04 | Action 步骤 | 显示工具图标 + 浅绿色背景，文本内容为工具名称和参数 JSON |
| FE-008-05 | Observation 步骤 | 显示结果图标 + 浅蓝色背景，文本内容为工具返回结果；超过 80 字符时支持展开/折叠 |
| FE-008-06 | 流式传输过程中新步骤到达 | 自动追加到时间线底部，无闪烁或跳动 |
| FE-008-07 | 无推理步骤（普通模式）| 不显示推理过程区域 |
| FE-008-08 | 抽屉关闭后再打开 | 推理步骤内容完整保留不丢失 |
