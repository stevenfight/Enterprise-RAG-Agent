# 变更提案：第一阶段重复逻辑收敛

## 背景

近期页面改造后，部分页面直接使用原生 `fetch`，与现有 `apiClient` 并存；知识库和设置页分别实现了同构状态概览卡片；图表页与图表容器分别实现了表格数据转换和渲染。

## 目标

- 统一图表、DAG 和健康检查请求到现有服务层与 `apiClient`。
- 抽取通用状态概览组件，保留知识库和设置页的业务数据计算。
- 抽取通用图表表格组件，避免页面和图表容器重复转换表格数据。
- 不改变接口、业务数据、路由和页面功能。

## 非目标

- 不处理后端 AgentMemory、配置读取和异常处理重复。
- 不统一所有空状态、加载状态和主题颜色。
- 不新增第三方依赖。
