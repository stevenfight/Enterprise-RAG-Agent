# 变更提案: 聊天界面可视化优化

> 编码: UTF-8

## 背景

在 `antdx-chat-upgrade`（聊天组件替换为 @ant-design/x）完成后，用户反馈整体观感仍不够协调，存在以下视觉问题：

1. 聊天页被全局 `Content` 的 `padding: 24` 内缩，聊天区未真正铺满，四周留白不自然。
2. 聊天相关组件中散落大量硬编码颜色（`#1a1a2e`、`#141420`、`#1a1a1a` 等），与 `theme.ts` 中定义的马卡龙主题 token 不一致，暗色模式下各区域颜色割裂。
3. SSE 流式输出时缺少"正在输入"的视觉反馈，交互感弱。

## 目标

- 聊天页铺满整个内容区，去掉多余的全局内边距。
- 收敛聊天组件中的硬编码颜色到 `theme.ts` 语义色，保证亮/暗色一致。
- 为流式输出的 AI 消息增加打字机光标，增强交互反馈。

## 范围

仅前端展示层，不涉及任何后端逻辑、SSE 协议、Zustand 状态管理变更。

## 非目标

- 不修改左侧「检索配置」面板的布局结构（仅统一其颜色 token）。
- 不修改数据图表页、DAG 看板、知识库、设置页。
- 不处理项目既有的 TypeScript 技术债（非本次范围）。
