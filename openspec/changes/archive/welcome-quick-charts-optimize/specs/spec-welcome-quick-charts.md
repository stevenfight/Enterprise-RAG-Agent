# 规格说明: 欢迎页 + 快捷指令 + 图表优化

> 编码: UTF-8

## 功能需求

### W1. 欢迎页快捷指令区

- 当 `quickCommands` 传入且消息列表为空、非加载状态时，在 `Welcome` 组件下方渲染快捷指令胶囊按钮。
- 每个胶囊显示一个问题文本，点击后直接调用 `onSend(question)`，不经过输入框。
- `quickCommands` 未传入或为空数组时，不渲染快捷指令区（欢迎页保持原样）。
- 快捷指令区仅出现在空对话态；一旦存在消息即隐藏。

### W2. 快捷指令视觉

- 胶囊按钮使用马卡龙描边色，hover 时轻微上浮 + 阴影加深。
- 图标使用「灯泡/闪电」类示意图标点缀。

### G1. 图表暗色适配

- `ChartContainer` 新增 `dark?: boolean` prop，默认 `false`。
- `dark=true` 时：
  - 图表标题颜色: `#e8e8e8`
  - 坐标轴/图例文字颜色: `#8c8c8c`
  - 容器卡片背景: `#1f1f1f`，边框: `#303030`
  - 空数据占位文字: `#6b6b6b`
- `dark=false`（默认）时保持现有配色不变（`#3D3554` / `#888` / `#ffffff` / `#e8e3ef`）。

### G2. 图表页主题跟随

- `ChartsPage` 通过 `useTheme()` 获取 `isDark`，将 `dark` 传给每个 `ChartContainer`。
- 页面标题、筛选卡片、空态文案颜色跟随主题。

## 验收场景

1. 空对话态下看到欢迎页 + 快捷指令胶囊，点击后问题被直接发送。
2. 有消息后快捷指令区隐藏。
3. 未传 `quickCommands` 时欢迎页不出现快捷指令区（向后兼容）。
4. 暗色主题下图表标题/坐标轴文字/容器背景为暗色配色，亮色主题不变。
