# 变更提案: 财务指标卡片化 + Markdown 表格美化

> 编码: UTF-8

## 背景

AI 回答中的财务数据（营收、增长率、净利润等）以纯 Markdown 表格和文本形式呈现，缺乏视觉层次感，关键数字不够突出，不符合"企业级财务分析"的高端定位。

## 目标

1. **Markdown 表格美化**：让表格呈现更专业的财务报告风格（斑马纹、表头渐变、数字等宽右对齐、圆角阴影、行 hover 高亮）。
2. **财务 KPI 卡片自动提取**：在 AI 回答中自动识别关键财务指标（营收、净利润、增长率等），在表格上方渲染 KPI 摘要卡片，让核心数据一眼可见。

## 方案

### 表格美化（formatMarkdown 增强）

在现有 `formatMarkdown()` 的表格渲染逻辑中升级样式：

- 表头：马卡龙紫渐变背景 + 白色文字 + 等宽字体
- 数据行：斑马纹（奇偶行不同背景）
- 数字列：自动检测数字内容 → 等宽字体 + 右对齐
- 表格外框：圆角 12px + 微阴影 + 无边框折叠
- 行 hover：背景色过渡高亮
- 暗色适配：暗色主题下自动切换配色

### KPI 卡片自动提取

新增 `extractFinancialKPIs(text: string)` 纯函数：

- 扫描文本中的财务指标模式：
  - 营收/收入：`营收.*?(\d[\d,.]+).*?亿元`
  - 净利润：`净利润.*?(\d[\d,.]+).*?亿元`
  - 增长率：`同比.*?增长.*?(\d[\d,.]+)%`
  - 其他：ROE、毛利率、资产负债率等
- 在 `MessageBubble` 中，AI 回答的 `formatMarkdown` 之前插入 KPI 卡片区域
- 卡片样式：马卡龙配色小卡片，图标 + 大数字 + 单位 + 变化趋势箭头

## 非目标

- 不改后端返回的数据格式。
- 不涉及前后端交互逻辑变更。
- 不添加外部图表库（D3/ECharts 等），保持轻量。
