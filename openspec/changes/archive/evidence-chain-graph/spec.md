# 需求规格

## 需求 1：严格引用映射

系统必须只将正文中出现且存在于当前消息 `sources` 的 `[来源N]` 视为已引用来源。

## 需求 2：关系展示

展开证据链后必须展示一个回答节点和当前消息来源节点，并清晰表达回答到来源的关系。

## 需求 3：来源定位

点击来源节点必须调用现有证据面板回调，并传递当前回答 ID 与来源 index。

## 需求 4：响应式和可访问性

证据链在窄屏可纵向阅读；入口和来源节点必须是可聚焦、可操作的按钮，并提供可理解的无障碍名称。

## 需求 5：不影响既有链路

回答正文、来源面板、SSE 流式更新、图表入口和复制/重新生成行为保持不变。
