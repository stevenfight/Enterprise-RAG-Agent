# 设计方案

## 数据流

`Message.content` 中的 `[来源N]` 与 `Message.sources[].index` 做严格交集。每个来源节点保留公司、文件、页码和引用状态；回答节点只展示当前回答摘要，不复制或重写正文。

## 交互

- 在回答底部现有证据入口旁增加“证据链”按钮。
- 点击后展开内嵌关系图；再次点击收起。
- 点击来源节点复用现有 `onViewEvidence(message.id, sourceIndex)`，打开完整证据面板并高亮对应来源。

## 视觉

使用现有页面 token，回答节点使用品牌色，来源节点使用中性表面，连线使用低对比边框；引用状态只通过标签和圆点表达，不使用额外彩虹色。

## 边界

正文没有 `[来源N]` 时，来源仍来自消息的 `sources`，但节点标记为“未在正文标记”；来源数组为空时不渲染入口。
