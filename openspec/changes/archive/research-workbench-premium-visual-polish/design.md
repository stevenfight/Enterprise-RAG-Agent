# 设计方案

## 视觉方向

采用“金融研究台”方向：中性石墨背景承载信息，金融青绿或深蓝只承担品牌和行动强调；成功、警告、错误继续使用独立语义色。卡片采用低对比边框和有限阴影，避免大面积渐变与紫色竞争。

## 实施范围

1. 在主题中补充页面背景、表面、悬浮表面和输入表面 token，并由 `AppLayout` 注入。
2. 将全局页面标题、卡片、摘要卡和辅助页工作区收敛到一致的密度与层级。
3. 让 `ant-sender` 和聊天底部区域跟随深浅模式，不再固定为白色块。
4. 调整图表摘要和辅助页的响应式网格，减少首屏空洞与卡片孤岛感。
5. 保留现有组件行为，仅通过 class 和 CSS token 做视觉调整。

## 风险控制

- 不删除旧 CSS 选择器，优先在后置的统一层覆盖旧的视觉值。
- 以现有页面测试、主题测试、响应式测试和浏览器逐页检查作为验收依据。
- 如果某个局部组件有专用设计，应继续沿用其现有语义色，不强行改成品牌色。
