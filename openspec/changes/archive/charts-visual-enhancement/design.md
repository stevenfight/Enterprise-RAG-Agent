# 设计方案：图表中心视觉增强

## 布局

图表列表使用 CSS Grid：桌面端两列，中等屏幕两列，移动端单列。表格模式保持全宽，避免复杂表格被压缩。

## 元信息

图表卡片标题下展示已有的 `source`、`period`、`created_at` 等字段；字段不存在时不渲染空标签。元信息使用次级文字和轻量标签，不改变图表主体面积。

## 空状态

当筛选结果为空时显示图表图标、说明文字和当前筛选提示；不新增业务按钮，不改变筛选状态。

## 约束

- 只修改 ChartsPage 及其样式和测试。
- 复用现有 `ChartContainer`、Ant Design 组件和页面主题变量。
- 不引入新依赖。
