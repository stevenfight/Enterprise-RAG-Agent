# 设计方案：DAG 看板视觉增强

## 页面结构

在 DAG 图前增加任务摘要区：

- 任务类型
- 节点数量
- 执行批次
- 当前状态

在 DAG 图后增加执行批次时间线，将现有 `execution_order` 的每一批节点转换为步骤卡片。空执行批次不显示时间线。

## 节点状态

使用现有节点 `status` 字段驱动状态类：等待、执行中、成功、失败和跳过。状态颜色仅用于视觉表达，不改变节点数据。

## 约束

- 组件接收现有 `DagPlanData`。
- 统计信息在前端从 `nodes`、`edges` 和 `execution_order` 计算。
- 不引入依赖。
- 亮色、暗色主题使用已有 CSS 变量。
- 移动端摘要卡片自动单列，时间线保持可读。
