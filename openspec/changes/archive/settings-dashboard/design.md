# 设计方案：设置页仪表盘改造

## 页面结构

在现有 `PageHeader` 后、详细配置卡片前增加 `settings-overview-grid`：

- Agent 状态：展示模型名称和加载状态。
- 向量数据库：展示可用状态和公司数量。
- 长期记忆：展示启用状态和容量。
- LangSmith：展示追踪启用状态和项目名。
- 工具注册：展示已启用工具数 / 工具总数。

保留下面三块现有详情卡片，不改变字段和请求逻辑。

## 视觉规范

- 使用 `page-card` 作为卡片基础样式。
- KPI 卡片使用图标、标签、主值和辅助说明四层结构。
- 状态颜色：成功使用绿色，未启用使用琥珀色，异常使用红色，未知使用灰色。
- 桌面端采用 5 列网格；中等宽度自动降为 3 列；移动端为 1 列。
- 颜色通过 CSS 变量继承亮色/暗色主题。

## 实现约束

- 新增 `SettingsOverview` 组件，输入 `SystemStatusData`，只负责展示。
- 工具启用数量由现有 `status.tools` 计算，不新增接口。
- 状态文本和颜色映射在组件内部集中定义，避免页面中重复判断。
- 不修改 `getSystemStatus`、类型定义和后端。
