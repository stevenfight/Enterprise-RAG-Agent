# 变更提案：设置页仪表盘改造

## 背景

当前设置页主要以纵向 Descriptions 展示 Agent 配置、系统健康和工具状态。信息完整，但用户需要逐行阅读才能判断系统是否可用，缺少一眼可见的运行概览。

## 目标

- 在设置页顶部增加系统状态 KPI 概览卡片。
- 统一模型、向量数据库、长期记忆、LangSmith 和工具注册状态的视觉表达。
- 保留现有详细配置和只读监控能力。
- 不新增后端接口，不改变状态数据结构和请求逻辑。
- 适配亮色、暗色和移动端布局。

## 非目标

- 不增加配置编辑功能。
- 不修改系统状态 API。
- 不重构其他页面。
- 不引入新的依赖。
