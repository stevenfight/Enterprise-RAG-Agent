# 变更提案：恢复前端生产构建

## 背景

前端当前 Vitest 和部分类型检查可运行，但生产构建被现有 TypeScript 类型错误阻塞，无法稳定产出部署包。

## 目标

- 收集并修复阻塞 `npm run build` 的类型错误。
- 保持现有页面功能、接口和视觉逻辑不变。
- 不引入新依赖，不进行无关重构。
- 让前端生产构建成功完成。

## 范围

- 修复构建错误涉及的组件、测试辅助类型和 Vite 配置类型。
- 为必要的类型修复增加最小验证。
- 更新 TDD、CHANGELOG 和交接记录。

## 非目标

- 不修改后端 API。
- 不修复与构建无关的业务问题。
- 不改变页面设计和用户交互。
