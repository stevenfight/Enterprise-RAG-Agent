# 规格说明: Planner 运营商别名识别（三大运营商）

> 编码: UTF-8

## 功能需求

### AL-1. 别名展开

- 新增别名映射：`"三大运营商" → ["中国移动", "中国联通", "中国电信"]`。
- 当查询文本包含别名时，将映射的公司名补充到识别结果中（去重，追加在精确命中公司之后）。

### AL-2. 分类与子任务

- 「对比三大运营商2024年的营业收入」→ 分类为 `multi_compare`，`company_names` 为三家运营商。
- compare 子任务 `tool_params["companies"]` 为三家运营商。
- 子任务描述显示「对比 中国移动、中国联通、中国电信: 2024年营收」。

### AL-3. 向后兼容

- 精确命中公司名的查询（如「中国移动和中国联通…」）行为不变。
- 无公司名、无别名的模糊查询行为不变。
- 公司提取逻辑收敛到私有方法 `_extract_companies(query)`，`_classify_query` 结构不变。

## 验收场景

1. `planner.plan("对比三大运营商2024年的营业收入")` 的 `company_names` 等于三家运营商。
2. 对应 compare 子任务的 `tool_params["companies"]` 等于三家运营商。
3. `planner.plan("中国移动和中国联通2024年营收对比")` 的 `company_names` 仍为这两家（顺序与数量不变）。
4. `planner.plan("2024年营收增长了么")` 的 `company_names` 仍为空。
