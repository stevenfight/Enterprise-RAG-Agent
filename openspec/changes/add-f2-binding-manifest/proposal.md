# 变更提案：为评测集增加数据集与来源清单绑定

## 背景

F2 已能核对样本引用的 PDF 是否存在、哈希/大小/物理页数是否与来源清单一致，但候选评测数据集和来源清单本身仍可能被替换。当前候选分支尚未装配完整评测集，因此需要一个轻量、可审计的绑定清单，明确评测集文件和来源清单文件的路径与 SHA-256。

## 目标

- 在评测 CLI 中可选读取绑定清单。
- 校验 CLI 实际使用的数据集、来源清单与清单记录的路径和 SHA-256 一致。
- 清单缺失、路径漂移或哈希漂移时失败关闭，并在报告中给出可定位原因。
- 保持没有传入绑定清单时的既有 CLI 行为不变。

## 非目标

- 不把 PDF 或完整评测集复制进候选分支。
- 不自动修改来源文件、评测数据集或发布状态。
- 不推送远端、不合并 `main`、不写入服务器。
