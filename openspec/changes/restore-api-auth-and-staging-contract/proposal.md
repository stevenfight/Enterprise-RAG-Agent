# 恢复 API SSE 鉴权、CORS 与 staging 凭据忽略契约

## 背景

视觉/发布集验收前恢复的保护测试发现 API 白名单重新放行 `/api/agent/stream`、严格 CORS 来源解析被移除，且 `.env.staging` 从忽略规则消失。这三项会分别造成 SSE 鉴权旁路、携带 Cookie 的跨域配置放宽和测试凭据误提交风险。

## 目标

在保留当前视觉/发布集 API 接入的基础上，恢复已验证的 API 鉴权、CORS 预检及 staging 环境忽略行为。

## 非目标

- 不更改视觉/发布集业务功能、部署、真实凭据或前端路由。
- 不改变已验证的 Bearer 与研究会话双路径。
