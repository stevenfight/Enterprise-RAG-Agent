# 变更提案：修复普通 RAG 财务金额单位换算

## 背景

普通 RAG 的通用、对比和财务数据提示词将检索文档的原始金额单位预设为“千元”。中国移动 2024 年营运收入在来源中按人民币百万元列报为 1,040,759；该错误前提会诱导模型输出 1,040.8 亿元，而正确值应为约 10,408 亿元。

## 目标

1. 让普通 RAG 与配置化 Agent 路径采用同一套“先读取来源单位、再换算”的规则。
2. 明确千元、百万元、万元到亿元的公式和百万元样例。
3. 以自动化回归测试保护中国移动的 10 倍量级错误。

## 非目标

- 不修改已入库报告、检索排序、模型、API 契约或前端图表数据。
- 不对模型输出进行缺少来源依据的后处理数值改写。
