# 变更提案：前端工作台整体一致性收口

## 背景

当前研究任务页已经完成局部工作台优化，但辅助页面仍同时使用 `AppLayout` 内容区内边距与 `PageShell` 内边距，导致页面在桌面端留白偏大、在移动端出现重复留白。顶部栏对 `/research` 路由未建立标题映射，进入研究任务时会显示默认“企业知识库”，与当前页面任务不一致。侧栏仍保留早期的渐变表面，与当前中性财务工作台的页面表面存在割裂。

## 目标

- 将非聊天页面的空间职责收敛到 `PageShell`，消除双层内边距。
- 让研究任务路由在顶部栏显示准确页面标题。
- 让研究任务工作台在无选中任务时提供明确的详情空态，避免主画布无内容。
- 将侧栏、内容区、键盘焦点、文本选中和滚动条等浏览器表面统一到当前主题变量。
- 保留所有路由、接口、权限、数据、轮询、登录和部署行为。

## 非目标

- 不重写各业务页面的功能或数据布局。
- 不增加后端接口、模拟数据、依赖、动画或图像资产。
- 不修改服务器、Nginx、Docker、企业微信、GitHub 分支或 `main`。

## 成功标准

- 非聊天页面仅由 `PageShell` 提供页面级内边距，主内容区不再重复留白。
- `/research` 顶栏显示“研究任务”。
- 侧栏与浏览器基础交互表面使用主题变量，键盘焦点可见。
- 定向 RED→GREEN 测试、前端全量测试、lint、构建、机械检测和桌面/移动视觉核查通过。
