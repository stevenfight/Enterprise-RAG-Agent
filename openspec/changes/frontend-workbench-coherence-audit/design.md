# 设计：前端工作台整体一致性收口

## 设计判断

本产品属于企业财务研究 Operate 界面。主路径是“在左侧切换工作区 → 阅读当前页面标题与状态 → 在主画布完成分析、资料管理或研究任务”。设计采用中性内容表面、单一主题强调色和紧凑但不拥挤的间距节奏，不引入营销式卡片、虚构指标或装饰性渐变。

## 空间模型

- `AppLayout` 负责应用视口、导航、顶部栏和内容滚动；非聊天路由不提供页面级内边距。
- `PageShell` 是辅助页面唯一的页面容器，负责最大阅读宽度、居中和 32/24/16px 响应式内边距。
- 聊天页维持既有全画布逻辑，避免改变输入区、消息区和会话侧栏。
- 侧栏使用与页面一致的中性表面，仅由当前主题色表示活动项和品牌标记。
- 研究任务页未选中任务时保留右侧详情区域，并用只读空态说明详情将在任务加载或选择后出现；不虚构任务数据或增加操作按钮。

## 主题与交互

- CSS 变量继续由 `AppLayout` 写入，页面、侧栏、选中态、滚动条、文本选择和焦点环从相同变量取值。
- 焦点环仅在键盘可见状态出现，使用主题色和足够的偏移量；不改变 Ant Design 控件语义。
- 研究路由补齐标题映射，避免页面标题与导航项目不一致。

## 响应式

- 桌面辅助页保持 `PageShell` 32px 内边距与 1320px 最大宽度。
- 1100px 及以下收紧为 24px，768px 及以下收紧为 16px；不由外层再叠加内边距。
- 已有聊天区的窄屏收起策略保持不变。

## 数据边界

本次改动不读取、不变换、不推断任何业务数据。所有可见文案仅来自既有路由名称和主题状态。
