# 恢复 SSE 研究会话与路由依赖基线

## 背景

候选工作区移除了 EventSource 的跨源凭据选项，并将 `react-router-dom` 从已提交的 `7.18.3` 降级为 `7.18.0`。两项改动均没有对应的需求或迁移说明，可能分别导致 HttpOnly 研究会话失效和依赖版本回退。

## 目标

恢复当前 HEAD 已验证的 SSE 会话传递契约和路由锁定版本，保留 URL 中不携带身份令牌的安全边界。

## 非目标

- 不改变后端鉴权、Cookie 属性、Nginx 或部署配置。
- 不升级其他依赖，不调整前端视觉或路由结构。
- 不推送远程、合并 `main` 或部署。
