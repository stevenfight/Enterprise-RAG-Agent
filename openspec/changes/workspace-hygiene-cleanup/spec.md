# 规格：工作区本地生成物忽略规则

## 要求

### 本地生成物忽略

系统必须忽略已确认的本地工具目录、运行会话数据、npm 缓存、预览图和调试记录。

#### 场景：检查本地生成物

- **当** 对目标路径执行 `git check-ignore -v`
- **则** 命令必须返回对应的 `.gitignore` 规则。

### 交付物可见性

系统必须继续显示功能交付物和规范交付物的 Git 状态。

#### 场景：检查功能交付物

- **当** 查询 `requirements.lock`、新增后端测试和 OpenSpec 归档目录的 Git 状态
- **则** 它们必须不被新的忽略规则排除。
