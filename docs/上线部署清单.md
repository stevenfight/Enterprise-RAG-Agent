## 五、运维注意事项

1. **新增文档后必须重建索引**: 新增 PDF 后，运行 `python src/ingestion.py --company <公司名> --rebuild`，否则检索结果不会包含新文档。
2. **定期备份**: 建议每周备份 `data/stock_data/databases/` 和 `config/` 目录。
3. **API Key 轮换**: 定期检查 DashScope API Key 有效期，提前更新 `.env` 文件。
4. **依赖更新**: 升级 faiss-cpu 或 dashscope 包前，在测试环境先运行自动化测试。
5. **日志保留**: 生产环境建议保留最近 30 天的日志，便于问题排查。
