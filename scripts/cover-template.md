# 封面图生成 Prompt

## 主题
知乎专栏文章封面图，展示"{title}"主题。

## 封面模板规范（严格遵循，与系列统一风格）

**画布尺寸**：1080 x 608 像素（16:9）

**背景**：
- 渐变暖色背景：#FFF9F5 → #FFF0E8（上到下或中心辐射）
- 4 个低透明度装饰圆形点缀在背景四角/边缘（浅色，透明度 10-20%）

**主卡片**：
- 白色半透明大卡片，圆角 rx=24
- 卡片阴影：flood-color #E8D5C8，柔和扩散
- 卡片居中偏上，占据画面 70-80% 区域

**左上角双标签**（严格位于卡片内部左上角）：
- 左侧标签："{series}" — 背景色 #D4A574（黄褐色），文字白色，圆角 pill 形状
- 右侧标签："第 {number} 篇" — 背景色 #A8D5BA（浅绿色），文字白色，圆角 pill 形状
- 两个标签并排，间距 12px
- 位置：卡片内部左上角，与卡片边缘保持适当内边距

**主标题**：
- 文字："{main_title}"
- 字号：52px，bold，颜色 #5A4A42
- 位于标签下方，居中

**副标题**：
- 文字："{subtitle}"
- 字号：28px，颜色 #9A8A82
- 位于主标题下方，居中

**分隔线**：
- 水平线，stroke #FADBD8（浅粉色），宽度 60%，居中
- 位于副标题下方，间距 20px

**信息卡片区**（4 个小卡片，横向等宽排列）：

卡片 1（绿色系 #D5F5E3）：
- 圆角 rx=16，带柔和阴影
- 文字："{card1_line1}" / "{card1_line2}"
- 文字颜色：#5A4A42
- 纯文字，无图标

卡片 2（黄色系 #FDF6E3）：
- 圆角 rx=16，带柔和阴影
- 文字："{card2_line1}" / "{card2_line2}"
- 文字颜色：#5A4A42
- 纯文字，无图标

卡片 3（粉色系 #FADBD8）：
- 圆角 rx=16，带柔和阴影
- 文字："{card3_line1}" / "{card3_line2}"
- 文字颜色：#5A4A42
- 纯文字，无图标

卡片 4（蓝色系 #EAF2F7）：
- 圆角 rx=16，带柔和阴影
- 文字："{card4_line1}" / "{card4_line2}"
- 文字颜色：#5A4A42
- 纯文字，无图标

**卡片颜色顺序必须严格为**：绿 → 黄 → 粉 → 蓝（从左到右）
**卡片形式**：纯文字，无图标，无插图

**底部署名**：
- 文字："{footer}"
- 字号：14px，颜色 #B8A898
- 位于画面最底部，居中

## 配色规范（马卡龙色系）

| 用途 | 色值 |
|------|------|
| 绿色系 | #D5F5E3 / #A8D5BA |
| 粉色系 | #FADBD8 / #D4847C |
| 黄色系 | #FDF6E3 / #D4A574 |
| 蓝色系 | #EAF2F7 / #B8D4E3 |
| 主文字 | #5A4A42 |
| 次要文字 | #9A8A82 |
| 背景渐变 | #FFF9F5 → #FFF0E8 |
| 阴影/分隔线 | #E8D5C8 |
| 底部署名 | #B8A898 |

## 风格要求

- 扁平矢量插画 (flat vector illustration)
- 所有元素使用圆角，无尖锐直角
- 阴影柔和、淡雅（#E8D5C8），不突兀
- 字体：PingFang SC / Microsoft YaHei
- 整体留白充足，不拥挤
- 禁止写实风格、禁止真实人脸、禁止过于鲜艳的颜色
- 禁止卡片内出现图标或插图，保持纯文字形式
